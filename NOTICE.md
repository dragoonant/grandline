# NOTICE

This is an **unofficial, non-commercial, fan-made** implementation of the **ONE PIECE CARD
GAME**, built to be played against a computer opponent on one machine.

**It is not affiliated with, endorsed by, sponsored by or approved by Bandai, Bandai Namco,
Eiichiro Oda, Shueisha or Toei Animation.**

ONE PIECE and the ONE PIECE CARD GAME are the property of their respective rights holders. The
game is named here once, to identify what this software implements.

## What this repository contains

- **Printed card text** from Bandai's official card list, in the single generated file
  `data/printed.js`. This is Bandai's copyrighted expression and is included so the cards read
  correctly. The game runs without it.
- **Character names**, which belong to Eiichiro Oda / Shueisha, in `js/names.js`.
- **Original illustrations**, generated for this project in an original style. No official
  illustration is reproduced and no prompt references an official artwork, artist or studio.
- **Original audio.** Every sound effect is generated for this project and the music is written
  by the program itself at runtime. **There is no third-party audio in this repository at all.**

## What this repository does NOT contain

- No official card images, scans or photographs.
- No official audio, music or voice.
- No manga or anime artwork.
- Nothing is sold, monetised, advertised or accepted as payment.

## Takedown

If you hold rights in any of the above and want this removed, see `docs/takedown.md`, which
carries the exact commands to strip the published text and the names and leave a playable game
behind. It will be done on request, without argument.
